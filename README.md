# ✨ Features

## 🎨 User Experience

- 🌙 Fully customizable theme system
- 🔨 Bug Patches for the original launcher!
- ⚡ Fast and responsive WinUI 3 interface
- 🖥️ Modern Windows 11 design language
- 🎉 Hidden Easter Egg

---

## 🌐 Live Services

- 👥 Real-time player count
- ⚡ Eon + update notifications
- 🛍️ Native Eon Item Shop with live rotations and item details
- 🌍 Web-powered content through WebView2

---

## 🎮 Discord Integration

- Rich Presence support
- Custom activity status
- Live launcher information

---

# 🛠️ Built With
